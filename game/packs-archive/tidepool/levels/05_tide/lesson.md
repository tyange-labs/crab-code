# 밀물과 썰물 — 데이터를 품은 enum

굴과 먹이 사이에 **갯벌**이 있어요. 밀물이 들어오면 갯벌은 물에 잠기고, 그 위에 있던 꽃게는 휩쓸려 굴로 떠밀려 와요. 들고 있던 먹이도 잃고요.

**새로 생긴 것**

- `Tile::Flat` — 물이 빠진 갯벌. `Tile::Water` — 깊은 물 (밀물에 잠긴 갯벌도).
- `view.tide()` 와 `Tide` — 지금 물때.

```rust
enum Tide {
    Low { turns_left: u32 },  // 물이 빠져 있음. turns_left 틱 뒤 밀물
    High { turns_left: u32 }, // 물이 차 있음. turns_left 틱 뒤 썰물
    Calm,                     // 물때가 없는 웅덩이
}
```

`Tide` 의 변형은 **데이터를 품고** 있어요. `match` 로 안의 값을 꺼내고, `if` **가드**로 조건을 붙일 수 있어요.

```rust
match view.tide() {
    Tide::Low { turns_left } if turns_left >= 6 => { /* 건너도 안전 */ }
    _ => { /* 기다리기 */ }
}
```

갯벌은 다섯 칸이에요. 건너는 동안 물이 들어오지 않으려면 언제 발을 들여야 할까요?

목표: 100틱 안에 먹이 2개를 굴로 가져오세요.

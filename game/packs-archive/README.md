# 보관 중인 게임팩

꽃게 이야기였던 옛 팩이에요. 게임이 찾는 `game/packs/` 밖이라 지금은 목록에 뜨지 않아요.
다시 쓰려면 폴더를 `game/packs/` 로 옮기세요. (`git mv game/packs-archive/<팩> game/packs/`)

- `tidepool` — 조수 웅덩이: 꽃게의 두뇌를 짜는 6레벨.
- `puzzle` — 퍼즐: 함수로 꽃게를 움직이는 51레벨 (『프로그래밍 러스트』 2~17장 순서).
- `farm` — 해바라기 농장: Sunnyside World 그림으로 만든 농장 이야기 14레벨(정거장 복구 팩의 원형). 그림 라이선스는 `farm/art/sunnyside/README.md` 참고.

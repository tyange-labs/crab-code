# 순찰 — Iterator 를 직접 만들기

이번 구역은 넓고 센서가 3걸음밖에 안 보여요. 코어가 어디 있는지 몰라서, **정해진 길로 훑고 다니다가** 코어가 보이면 달려가야 해요.

**새로 생긴 것은 없어요.** 대신 **훑고 다닐 길을 알려 주는 반복자**를 직접 만들어요.

반복자는 값을 **하나씩 차례로** 내놓는 것이에요. `for`, `map`, `filter`, `min_by_key` 같은 도구가 전부 반복자 위에서 일해요. 내 타입도 `Iterator` 트레이트를 구현하면 그 도구를 다 쓸 수 있어요.

```rust
struct Sweep {
    points: Vec<(i32, i32)>, // 차례로 들를 지점
    next_index: usize,
}

impl Iterator for Sweep {
    type Item = (i32, i32);   // 내놓는 값의 타입

    fn next(&mut self) -> Option<(i32, i32)> {
        // 다음 지점을 내놓고, 마지막이면 처음으로 돌아가요 (끝없이 순찰)
    }
}
```

`Iterator` 에서 **꼭 만들 것은 `next` 하나**예요. 값이 있으면 `Some(값)`, 더 없으면 `None` 을 돌려줘요. 나머지 도구는 `next` 를 바탕으로 저절로 생겨요. 예를 들어 `sweep.take(3)` 은 처음 세 지점만, `sweep.next()` 는 다음 지점 하나예요.

여기서는 `None` 을 돌려주지 않고 **끝없이 순환**해요. 지점이 `[A, B, C]` 면 `A, B, C, A, B, C, …` 로 계속 나와요. (`%` 나머지 연산으로 인덱스를 돌려요.)

순찰 길은 지도를 **지그재그**로 훑는 것이 좋아요. 시야가 3걸음이라 줄 사이를 2칸씩 띄우면 지도 전체가 눈에 들어와요. 이 구역 지도는 가로 21, 세로 9 인데 안쪽 가로줄이 `y = 1..7` 이에요.

```text
(19,1) → (19,3) → (1,3) → (1,5) → (19,5) → (19,7) → (1,7) → …
```

로봇이 할 일:

1. 코어를 들고 있으면 `reactor_dir()` 로 반응로로 가요.
2. 발밑이 코어면 집어요.
3. 시야 안(`view.sight()` 걸음)에 코어가 보이면 `tile_at` 으로 찾아 가까운 것으로 가요.
4. 아무것도 안 보이면 **순찰 지점** 으로 가요. 지점에 닿으면 `sweep.next()` 로 다음 지점을 받아요.

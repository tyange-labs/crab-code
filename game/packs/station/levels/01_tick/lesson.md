# 로봇의 두뇌, tick

**시작하는 법**

1. 좋아하는 **IDE**(VS Code, RustRover, Zed …)로 작업 폴더를 열어요. 윗줄 `⋯` 메뉴의 **IDE 로 열기**(⌘O)를 누르면 이 레벨 파일 `01_tick.rs` 가 바로 열려요.
2. 파일의 `// …` 주석이 알려 주는 곳을 고치고 **저장**해요 (⌘S).
3. 저장하면 게임이 알아채서 **자동으로 빌드하고 실행**해요. 결과는 오른쪽 화면에서 재생되고, 컴파일 에러가 나면 **문제** 탭에 그 줄과 함께 떠요.

막히면 아래 **힌트**를, 그래도 어려우면 **정답 보기**를 눌러요. (재생 `Space`, 틱 이동 `←` `→`, 힌트 `H`)

지금부터 **로봇의 두뇌**를 만들어요. 로봇을 직접 조종하지 않아요. 게임이 매 **틱**(한 박자)마다 로봇의 `tick` 을 불러 "이번엔 뭘 할래?" 하고 묻고, 로봇은 할 일 하나를 돌려줘요.

파일을 보면 세 부분이 있어요.

- `struct Echo;` — 로봇 한 마리를 나타내는 타입이에요.
- `impl Bot for Echo { … }` — `Echo` 가 로봇의 두뇌(`Bot` 트레이트) 노릇을 하게 해요. `new` 는 로봇을 만들고, `tick` 은 할 일을 골라요.
- `fn main() { play::<Echo>(); }` — 이 레벨을 `Echo` 로 플레이해요.

`tick` 이 돌려주는 `Action` 은 **함수가 아니라 값**이에요. `Action::Wait` 는 "가만히 있겠다"는 뜻의 값이고, `Action::Move(Dir::East)` 는 "동쪽으로 걷겠다"는 뜻의 값이에요. `Move` 는 방향(`Dir`) 값을 하나 품고 있어요.

지금 쓸 수 있는 것은 이게 다예요.

- `Action::Wait`, `Action::Move(dir)`
- `Dir::North`, `Dir::East`, `Dir::South`, `Dir::West`
- `view.tick()` — 지금 몇 번째 틱인지

IDE 에서 `Action` 위에 커서를 두고 **F12**(정의로 이동)를 누르면 이 레벨에서 쓸 수 있는 것만 모아 둔 파일이 열려요. 레벨을 넘길 때마다 하나씩 늘어나요.

목표: 동쪽의 코어가 있는 칸까지 걸어가세요.

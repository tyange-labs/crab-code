# 에너지 — 참조를 품은 구조체와 라이프타임

이번 로봇은 **배터리**로 움직여요. 한 걸음 걸을 때마다 에너지가 1 줄고, **0 이 되면 못 걸어요.** 반응로나 **충전 패드**(`Tile::Pad`) 위에 서면 가득 차요. 한 번 충전으로 걸을 수 있는 건 20걸음이에요.

**새로 생긴 것**

- `view.energy()` — 남은 에너지 (걸을 수 있는 걸음 수).
- `view.pads()` — 충전 패드들의 위치 목록.
- `view.reactor()` — 반응로 위치.
- `Tile::Pad` — 충전 패드.

코어까지 갔다가 **돌아올 에너지가 남는지** 미리 따져야 해요. 이럴 때 계산을 한곳에 모으는 작은 구조체가 있으면 좋아요. 그런데 그 구조체가 `view` 를 **빌려서** 들고 있으려면 어떻게 할까요?

```rust
struct Budget<'a> {
    view: &'a View,   // View 를 소유하지 않고 빌려요
}
```

구조체가 **참조**를 품으면 `'a` 같은 **라이프타임 이름표**를 꼭 붙여야 해요. "이 `Budget` 은 `'a` 만큼만 살 수 있다 — 빌려 온 `View` 보다 오래 살면 안 된다"는 뜻이에요. 컴파일러가 그걸 확인해서, 빌린 값이 사라진 뒤에 쓰는 실수를 막아 줘요.

`impl` 에도 같은 이름표를 적어요.

```rust
impl<'a> Budget<'a> {
    fn new(view: &'a View) -> Budget<'a> {
        Budget { view }
    }

    fn can_afford(&self, steps: u32) -> bool {
        self.view.energy() >= steps
    }
}
```

`tick` 안에서 만들어 쓰고 `tick` 이 끝나면 함께 사라지게 하면 돼요.

```rust
let budget = Budget::new(view);
if budget.can_afford(10) { /* … */ }
```

판단 규칙은 이래요.

1. **코어를 들고 있으면**: 반응로까지 갈 에너지가 되면 반응로로, 모자라면 가까운 충전 패드로 먼저 가요.
2. **빈손이면**: 가장 가까운 코어까지 가고 + 거기서 가장 가까운 충전 지점(반응로나 패드)까지 돌아올 에너지가 되면 코어로, 아니면 **그 코어에서 가장 가까운 충전 지점**으로 먼저 가서 가득 채우고 출발해요.

거리는 가로 + 세로 걸음 수(맨해튼 거리)로 어림해도 돼요.

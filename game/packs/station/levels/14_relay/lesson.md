# 통신 채널 — static 과 Mutex

로봇이 **네 명**이에요. 모두 "가장 가까운 빈 슬롯"으로 달려가면 **한 슬롯에 몰려요.** 그래서 **통신 게시판**에 "이 슬롯은 내가 맡았어요" 하고 적어 두려고 해요.

그런데 로봇은 각자 따로 만들어진 `Echo` 값이에요. 서로 **같은 게시판**을 보려면 `Echo` 밖에, 모두가 함께 쓰는 곳에 둬야 해요. 프로그램 전체에서 하나뿐인 값은 **`static`** 으로 만들어요.

```rust
use std::sync::Mutex;

/// 맡은 슬롯 목록 (로봇 모두가 함께 봐요).
static BOARD: Mutex<Vec<(i32, i32)>> = Mutex::new(Vec::new());
```

`static` 은 여러 곳에서 동시에 읽을 수도 있어서, Rust 는 **바꿀 수 있는 `static`** 을 그냥 못 쓰게 해요. 대신 **`Mutex`** 로 감싸요. `Mutex` 는 "한 번에 하나만 열 수 있는 자물쇠 상자"예요. 열려면 `lock()` 을 불러요.

```rust
let mut board = BOARD.lock().unwrap(); // 자물쇠를 잡고 안의 값을 빌려 와요
board.push((x, y));                    // 맡았다고 적어요
// board 가 범위를 벗어나면 자물쇠가 저절로 풀려요
```

`lock()` 은 다른 곳에서 패닉 중이면 `Err` 일 수 있어서 `Result` 를 돌려줘요. 여기서는 `unwrap()` 으로 충분해요.

이번 구역은 센서 범위가 넓어서 `tile_at` 으로 지도 전체를 볼 수 있어요. 한 슬롯의 일생은 이렇게 맡겨요.

1. 아무도 안 맡은 가장 가까운 `Tile::Slot` 을 골라 게시판에 적고 그리로 가요 (`self.claim`).
2. 도착하면 설치하고(`Install`), 충전하고(`Charge`), 코어가 생길 때까지 기다려요.
3. 코어를 집으면(`Grab`) 게시판에서 지우고 반응로로 가요.

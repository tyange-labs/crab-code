# 정책 — 클로저와 Fn 경계

이번 구역에는 코어가 흩어져 있고 **경비 드론 두 대**가 세로로 오가요. 무조건 가장 가까운 코어로 가면 드론 길목에 들어가서 코어를 잃기 쉬워요. "가까울수록 좋고, 드론 길목이면 나쁘다" 같은 **점수 규칙**으로 고르고 싶어요.

**새로 생긴 것은 없어요.** 대신 **점수 규칙을 값으로** 넘겨요.

**클로저**는 이름 없는 작은 함수인데, 만들어진 곳의 **변수를 가져다 쓸 수 있어요.**

```rust
let drones = vec![(6, 3), (8, 3)];
let penalty = 8;
let score = |c: (i32, i32)| {
    let near = drones.iter().filter(|d| (d.0 - c.0).abs() <= 1).count() as i32;
    (c.0 - 1).abs() + (c.1 - 1).abs() + penalty * near   // drones 와 penalty 를 가져다 썼어요
};
```

이 `score` 를 **함수의 인자로** 넘길 수 있어요. 그때 "이 인자는 `(i32, i32)` 를 받아 `i32` 를 돌려주는 호출 가능한 것"이라고 **`Fn` 경계**로 적어요.

```rust
fn pick<F>(cores: &[(i32, i32)], score: F) -> Option<(i32, i32)>
where
    F: Fn((i32, i32)) -> i32,
{
    cores.iter().copied().min_by_key(|&c| score(c))
}
```

같은 `pick` 으로 규칙만 바꿔 끼울 수 있어요. 서로 다른 클로저는 서로 다른 타입이라서, 어떤 클로저든 받으려면 이렇게 **제네릭(`F`) + `Fn` 경계**를 써요.

- `Fn` — 가져온 값을 **읽기만** 해서 여러 번 불러도 돼요.
- `FnMut` — 가져온 값을 **바꿔요.**
- `FnOnce` — 가져온 값을 **소비**해서 한 번만 불러요.

클로저는 기본적으로 가져온 값을 **빌려요.** 클로저가 만들어진 곳보다 오래 살아야 하면(스레드에 넘기거나 함수가 클로저를 돌려줄 때) `move` 를 붙여 **주인을 넘겨요.**

로봇이 할 일:

1. 보이는 경비 드론 위치를 모아요 (`view.tile_at(x, y) == Ok(Tile::Sentry)`).
2. `pick` 에 "거리 + 드론 길목 벌점" 클로저를 넘겨 코어를 골라요.
3. 걸을 때는 `view.danger(dir)` 이면 기다려요.

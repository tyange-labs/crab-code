`Insert`: `(view.here() == Tile::Reactor && view.carrying()).then_some(Action::Insert)`, `Grab`: 발밑이 `Tile::Core` 이고 들고 있지 않을 때. `Charge`: 발밑이 `Tile::Module` 일 때. 마지막 `Walk` 는 `let dir = if view.carrying() { view.reactor_dir() } else { view.core_dir().or(view.slot_dir()) };` 로 방향을 고르고 `match dir { Some(d) if view.danger(d) => None, Some(d) => Some(Action::Move(d)), None => None }`.
